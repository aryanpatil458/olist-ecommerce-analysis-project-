# 🛒 Olist E-Commerce Data Analysis

## 📌 Overview

An end-to-end **E-Commerce Data Analysis project** using SQL and Power BI to analyze sales, customers, products, payments, delivery performance, and customer satisfaction.

The project includes **15+ business questions** covering:

* 📈 Sales & Trend Analysis
* 👥 Customer Analysis
* 🔄 Retention Analysis
* 👑 RFM Customer Segmentation
* 💰 Customer Lifetime Value
* 🛒 Market Basket Analysis
* 🚚 Delivery & Review Analysis
* 💳 Payment Analysis

## 🗃️ Dataset

**Brazilian E-Commerce Public Dataset by Olist**

The dataset is available on Kaggle and contains approximately **100,000 orders from 2016–2018** across multiple marketplaces in Brazil. It includes information about orders, customers, products, sellers, payments, freight, delivery, and customer reviews.

**Source:** [Kaggle — Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce?utm_source=chatgpt.com)

## 🛠️ Tools Used

* **PostgreSQL / SQL** — Data analysis & business queries
* **Power BI** — Interactive dashboards & visualization
* **GitHub** — Documentation & project portfolio

## 📊 Key Analysis

The project answers questions such as:

* How is revenue changing over time?
* Which categories generate the most revenue?
* Which states are the strongest markets?
* What payment methods are most popular?
* How often are orders delivered late?
* Does late delivery affect review scores?
* Who are the most valuable customers?
* Which customers are at risk?
* Which product categories are purchased together?
